# Личные финансы (УП.01.01)

Учебная практика УП.01.01. Тема: «Проектирование и разработка базы данных для сервиса по управлению личными финансами и бюджетом».

Автор: Ульяненко.

## Стек

- Microsoft SQL Server (Express) + SSMS
- WPF, .NET Framework 4.7.2
- Entity Framework 6, Database First (ADO.NET Entity Data Model, `.edmx`)
- Microsoft Office Interop (Word, Excel) для отчётов

## База данных

БД `DB_Ulianenko_Finance`, 3 таблицы:

| Таблица | Назначение |
|---|---|
| `Users` | пользователи: логин, хэш пароля (SHA-256), роль, ФИО, фото, тема |
| `Category` | категории операций, тип «Доход» / «Расход» |
| `Operation` | операции пользователя: дата, название, сумма, комментарий |

`Operation` связана с `Users` и `Category` внешними ключами с каскадным удалением.

### Как развернуть

1. Открыть SSMS и подключиться к `.\SQLEXPRESS`.
2. Открыть и выполнить скрипт `db/schema.sql`.

## Как запустить

1. Открыть `Finance.slnx` в Visual Studio.
2. Проверить строку подключения `DB_Ulianenko_FinanceEntities` в `Finance/App.config`.
3. Запустить проект (F5).

## Страницы и функции

| Страница | Заголовок | Что делает |
|---|---|---|
| `AuthPage` | Авторизация | вход по логину и паролю, переход по роли, капча после 3 неверных попыток |
| `RegPage` | Регистрация | новый пользователь, проверка логина и пароля, выбор роли |
| `ChangePassPage` | Смена пароля | смена пароля по логину и текущему паролю |
| `UserPage` | Мои операции | свои операции: поиск, фильтры по категории, типу и периоду, сортировка, итоги; добавление, правка и удаление своих операций |
| `AdminPage` | Панель администратора | переход к разделам управления, диаграмме и отчётам |
| `UsersTabPage`, `AddEditUserPage` | Пользователи | список, поиск, фильтр по роли, сортировка, добавление, правка, удаление |
| `CategoryTabPage`, `AddEditCategoryPage` | Категории | список, поиск, фильтр по типу, сортировка, добавление, правка, удаление |
| `OperationTabPage`, `AddEditOperationPage` | Операции | операции всех пользователей, поиск, фильтр по пользователю, сортировка, добавление, правка, удаление |
| `DiagramPage` | Диаграмма | суммы по категориям для выбранного пользователя, выбор типа диаграммы и Доход / Расход |
| `ReportPage` | Отчёты | выгрузка в Word (.docx), PDF и Excel (.xlsx) |

Общее для всех страниц:

- пароли хранятся только хэшем SHA-256;
- удаление и выход только после подтверждения;
- удаление пользователя или категории удаляет и связанные операции (каскад в БД);
- светлая и тёмная тема, выбранная тема сохраняется у пользователя;
- плейсхолдеры и всплывающие подсказки в полях, маски ввода, проверка данных перед сохранением.
